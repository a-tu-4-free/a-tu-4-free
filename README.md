# ATU — LIVE 4 FREE

### Independent Developer of Useful & Useless Things.
### 有用與無用事物的獨立開發者。

這裡存放一些想法、實驗、工具，以及偶爾不知道為什麼要做出來的東西。

A collection of ideas, experiments, tools, and things that occasionally make me wonder why I built them in the first place.

有些是為了解決問題，有些是為了製造問題，有些則是為了讓某些人看起來更有問題。

Some are built to solve problems, some to create problems, and some to make certain people look even more problematic.

### What I Do / 我在做什麼

- **政治諷刺 Political Satire** — 嘲諷政客，偶爾順便嘲諷自己。  
  Making fun of politicians, and occasionally myself.

- **無用工具 Useless Tools** — 開發一些有用、無用，以及介於兩者之間的小工具。  
  Building useful, useless, and everything in between.

- **資訊應用 Information & Data** — 把公開資訊變成有趣或實用的東西。  
  Turning public information into something interesting or useful.

- **自動化 Automation** — 自動化那些不值得浪費時間的事情。  
  Automating things that aren't worth wasting time on.

- **各種實驗 Random Experiments** — 偶爾認真寫點程式，假裝自己很專業。  
  Occasionally writing serious code while pretending to be a professional.
